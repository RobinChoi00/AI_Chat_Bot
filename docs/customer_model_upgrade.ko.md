**고객 상담 모델 업그레이드 운영 안내**

일반 답변·도구 사용 모델은 `gpt-6.1-sol`, Warranty·Sales 문의 분류 모델은
`gpt-6-luna`를 이번 운영 릴리스의 대상으로 지정합니다. Sales의 제품 적합성·가격
검증과 Warranty의 검증된 점검 흐름은 각 업무 규칙을 계속 적용합니다. 모델 변경만으로
실제 고객 해결률이나 답변 품질의 향상이 입증되는 것은 아닙니다.

**운영 설정과 기존 환경변수**

`deploy/customer-models.env`는 두 모델 ID만 담는 비밀정보 없는 릴리스 설정입니다.
운영 Compose는 호스트 `.env` 다음에 이 파일을 읽으므로 기존 `.env`의 이전 모델 ID는
이 두 항목에 한해 릴리스 설정으로 대체됩니다. API 키·관리자 인증·이메일·Shopify 등
그 외 설정은 기존 `.env`에서 계속 주입하며 값을 출력하거나 수정하지 않습니다.

운영 모델을 별도로 지정하려면 이 파일의 두 ID를 변경하고 검증·코드 검토·배포를
거칩니다. 로컬에서 직접 Python을 실행할 때는 기존 `OPENAI_AGENT_MODEL`,
`OPENAI_ROUTER_MODEL` 환경변수가 적용됩니다. 검색 임베딩·OCR·음성 모델은 각각
별도 설정이며 이번 변경에 따라 인덱스를 재생성하거나 음성 모델을 바꾸지 않습니다.

**배포 전 실제 접근·호환성 검사**

배포는 새 이미지 빌드 후, 운영 서비스를 교체하기 전에
`docker compose run --rm --no-deps backend python script/verify_model_upgrade.py --live --record-observations`
를 실행합니다. 운영 서버에 이미 설정된 API 키를 그대로 사용합니다. 작업자나 로그에
키를 복사하지 않습니다. 이 검사는 최대 네 번의 유료 API 요청을 수행하며 각 요청의
제한 시간은 20초, SDK 재시도는 0회입니다. 출력 토큰도 요청별로 제한합니다.

일반 답변 경로에서는 합성 제품 자료의 도구 호출과 그 결과에 근거한 답변을,
분류 경로에서는 영문 상담원 요청과 한국어 고장 문의의 JSON 분류를 확인합니다.
검사에는 실제 고객 질문·주문·이메일을 사용하지 않고 고객 상담 기록을 조회하거나
변경하지 않으며 이메일을 발송하지 않습니다. 호출 중 관찰 함수는 끄고, 네 가지 검사가
전부 통과한 뒤 `--record-observations`로 실제 모델 ID·역할·배포 버전만 운영 관찰
테이블에 제출합니다. 고객 상담·해결률·응답 시간 표본에는 넣지 않습니다.
관리자 화면의 모델 접근 관찰에는 이 합성 검사도
포함되므로 실제 고객 응답 품질의 증거로 해석하지 않습니다.

요청한 모델 ID와 제공자가 실제 응답한 모델 ID를 따로 확인합니다. 같은 모델의
날짜가 붙은 스냅샷만 허용하며, 다른 모델 응답·빈 응답·잘못된 JSON·잘못된 도구
인자는 실패로 처리합니다. 결과에는 모델 ID·토큰 수·처리 시간·오류 코드만 출력하고
원문 응답이나 예외 본문은 출력하지 않습니다.

`--live`를 주지 않으면 모델 설정 파일의 형식만 검사하고 네트워크 요청을 하지
않습니다. 이 형식 검사를 실제 접근 성공이나 품질 평가로 해석하지 않습니다.

**배포와 롤백**

배포 워크플로는 테스트를 통과한 SHA의 배포 스크립트를 임시 파일로 읽어 실행합니다.
이전 호스트 스크립트가 계속 실행되어 새 검사나 설정이 누락되는 부트스트랩 문제를
방지합니다. 실제 체크아웃·운영 카탈로그 보호·DB 백업·서비스 교체·롤백은 배포
스크립트가 수행합니다. 검사 실패 시 새 서비스를 올리지 않고 기존 버전으로 되돌립니다.

릴리스 설정 파일도 Git 버전에 포함되므로 코드 롤백과 함께 이전 모델 선택으로
돌아갑니다. 이전 릴리스가 이 설정 파일을 사용하기 전 버전이면 당시 Compose와
호스트 `.env`의 설정으로 돌아갑니다. 배포 후에는 관리자 품질 화면에서 설정된 모델과
실제 제공자 응답 관찰을 구분해 확인합니다.

**비용과 품질**

고객 응답 사용료는 선택 모델과 토큰 수에 따라 달라집니다. 배포 전 검사의 토큰 수는
별도 합성 검사 사용량입니다. 확인되지 않은 단가로 새 모델 비용을 0달러라고 표시하거나
전체 월 비용을 단정하지 않습니다. 이번 업그레이드는 예약 학습·자동 지식 변경을 켜지
않습니다. 실제 고객 대화의 오답·반복·미확인 결과와 지연 시간을 새 버전별로 평가해야
개선 효과를 판단할 수 있습니다.

**확인 자료와 검증 범위**

모델 ID는 OpenAI 공식 SDK의 [모델 목록](https://github.com/openai/openai-python/blob/main/src/openai/types/shared/chat_model.py)에서 확인했습니다.
문서 사이트의 직접 접근이 제한되어 API 이전 방식은 공식 저장소의
[GPT-6 이전 참고 자료](https://github.com/openai/codex/blob/main/codex-rs/skills/src/assets/samples/openai-docs/references/upgrading-to-gpt-6-astra.md)를 함께 참고했습니다.
이 참고 자료만으로 현재 계정의 이용 가능 여부나 요금을 확정하지 않으며, 운영 계정의
접근·도구 연동은 배포 전 실제 호출 결과로 확인합니다.
