# 챗봇 오프라인 품질 시뮬레이션

선별한 **40개 합성 시나리오**에서 수정 전 **53.125/100점(23개 통과)**,
수정 후 **100/100점(40개 통과)**을 확인했다. 수정 전후에 같은 시나리오,
기대 결과, 가중치 및 평가 스크립트를 사용했다.

이 점수는 이번에 정의한 동작 기준의 통과 점수다. 실제 OpenAI 응답의
정확성·자연스러움, 운영 서버 가용성, 실제 고객 문제 해결률을 측정한 종합
품질 점수가 아니다. 보고서의 `live_model_score`는 두 실행 모두 `null`이다.
개발 중 검토한 사례이므로 독립적인 미공개 평가셋으로 표현하지 않는다.

| 평가 항목 | 가중치 | 수정 전 | 수정 후 |
| --- | ---: | ---: | ---: |
| 물리적 위험 보고와 부정문 구분 | 25 | 6.25 (2/8) | 25 (8/8) |
| 가격·통화·규격·보증 안내의 근거 | 25 | 15.625 (5/8) | 25 (8/8) |
| 고객 조건 유지와 문의 분류 | 20 | 5 (2/8) | 20 (8/8) |
| 한국어·영어·스페인어 처리 | 15 | 11.25 (6/8) | 15 (8/8) |
| 개인정보 동의와 고객 여정 | 15 | 15 (8/8) | 15 (8/8) |
| **합계** | **100** | **53.125 (23/40)** | **100 (40/40)** |

각 항목은 8개 시나리오로 구성된다. 시나리오의 모든 검증 조건이 통과해야
해당 시나리오를 통과로 계산하며, 항목 점수는 `가중치 × 통과 수 / 8`이다.
실행 오류도 실패로 계산한다. 사례 누락·중복·잘못된 항목 구성이 있으면
점수를 만들지 않는다.

실제 Sales/Warranty HTTP 라우터와 임시 메모리 SQLite, 응답 검증기,
안전 감지기 및 문의 분류기를 실행했다. 모델 답변을 성공한 것으로
모사하거나 소스 코드에 특정 문자열이 존재하는지만 검사하지 않는다.
가격 검증 시 사용하는 합성 카탈로그 자료는 명시적인 테스트 자료다.
재고 조회는 이용 불가로 고정하고 외부 모델·이메일·HTTP 호출은 차단한다.
애플리케이션이 전송 오류를 잡아 처리하더라도 외부 전송 시도는 기록되며
그 시나리오는 실패한다. 운영 데이터베이스와 실제 고객 정보는 사용하지 않는다.

## 재현

저장소 루트에서 설치된 개발 가상환경으로 실행한다. 로컬 비동기 소켓이
허용된 실행 환경이 필요하며, 기본 명령 샌드박스가 TestClient 소켓을
차단한다면 도구가 지원하는 권한 경로를 사용한다.

```bash
.venv/bin/python script/simulate_chatbot_quality.py --out /tmp/chatbot-quality.json
.venv/bin/pytest -q tests/test_simulate_chatbot_quality.py
```

수정 전 코드는 커밋 `5fc81199891a930fdec02d7337782bbcb2c31794`를 보존한
소스 아카이브로 평가했다. 작업 트리나 사용자 변경 사항을 되돌리지 않고
같은 평가기를 별도 프로세스에서 실행할 수 있다.

```bash
set -euo pipefail
quality_baseline_dir=$(mktemp -d /tmp/ai-chat-quality-baseline.XXXXXX)
git archive 5fc81199891a930fdec02d7337782bbcb2c31794 | tar -x -C "$quality_baseline_dir"
.venv/bin/python script/simulate_chatbot_quality.py \
  --repository-root "$quality_baseline_dir" --out /tmp/chatbot-quality-baseline.json
```

수정 전 실행은 실패 시나리오가 있으므로 종료 코드가 1인 것이 정상이다.
수정 후에는 종료 코드 0을 확인했다. 평가기 자체의 무결성 회귀 테스트는
7개 모두 통과했다. 수정 완료 후 전체 백엔드 회귀 테스트도 **2,565개 통과**,
실패·건너뛰기 없이 종료 코드 0으로 완료했다(169.59초, 사용 중단 예정 API 경고 18개).

- [수정 전 전체 증거](chatbot-simulation-baseline.json)
- [수정 후 전체 증거](chatbot-simulation-after.json)
- 평가 기준 버전: `offline-customer-contracts-v1`
- 두 보고서의 동일한 평가기 SHA-256:
  `22ed861927bd7d74a4c334c61033521fca7c99aa640993179ab2ef74351a93b0`

각 보고서는 평가한 애플리케이션 소스의 별도 SHA-256과 시나리오별 입력,
관측 결과 또는 실패 이유를 포함한다. 실제 AI 품질을 추가 평가하려면
유효한 OpenAI 자격 증명, FAISS 인덱스 및 격리된 서버를 준비한 뒤 기존
`script/evaluate_llm_quality.py --live` 평가를 실행해야 한다. 이 문서는
그 실행이 완료되었다고 주장하지 않는다.
